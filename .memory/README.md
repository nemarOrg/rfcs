# `.memory/`: what working on this repository taught

One observation per file, named in kebab case, with YAML frontmatter (`name`, `description`, `metadata.type`).
A memory is an observation that cost someone time.
It binds nobody: a ruling lives in nemarOrg/nemar-cli `.context/decisions/` or in `PROCESS.md`, and wins over anything here.
Correct or delete a memory that turns out wrong.

The program handoff is [`../.context/handoff.md`](../.context/handoff.md).
